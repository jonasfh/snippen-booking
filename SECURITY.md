# Security Policy

## Supported Versions

Only the latest major release of Snippen Booking receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Snippen Booking, please report it responsibly rather than opening a public GitHub issue.

- **Private Reporting**: Please use [GitHub Private Vulnerability Reporting](https://github.com/jonasfh/snippen-booking/security/advisories/new) or contact the repository maintainer directly.
- **Response Time**: We aim to acknowledge reports within 48 hours and provide status updates as fixes are developed, tested, and released.
